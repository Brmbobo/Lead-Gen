## EXECUTION COMMANDS

### Spustenie celého workflow
```bash
# Aktivácia Queen Coordinator na orchestráciu
claude --agent queen-coordinator --task "Execute Lead-Gen Enterprise Plan"
```

### Spustenie konkrétnej fázy
```bash
# Fáza 1: Core Infrastructure
claude --agents "integration-architect,security-architect,worker-specialist" \
       --parallel \
       --task "Implement Phase 1: Core Infrastructure"
```

### Spustenie review cyklu
```bash
# Review pipeline
claude --agents "code-analyzer,code-reviewer,production-validator" \
       --sequential \
       --task "Review and validate Phase 1 deliverables"
```
